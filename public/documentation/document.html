Introduction & Setup

1. Product Overview: CarePulse Hospital & Clinical Admin

CarePulse is a state-of-the-art, high-performance, and feature-complete Hospital & Clinical Operations Admin Dashboard template built with React 19, Tailwind CSS v4, and Vite 8. Engineered with modular architecture, isolated reusable UI components, and cutting-edge visual aesthetics, CarePulse delivers everything needed to build production-ready clinical and administrative healthcare applications.

Key Highlights

  • Modern Tech Stack: Powered by React 19, Tailwind CSS v4, and Vite 8 for blazing fast Hot Module Replacement (HMR) and optimized build outputs.
  • 32+ Pre-built Pages: Comprehensive suite of specialized pages for Clinical Command Center, Emergency & Trauma Triage, Bedside Telemetry, Inpatient Registry, Physician & Staff Roster, Ward Occupancy & Bed Management, Stat Lab Diagnostics, Hospital Pharmacy & Dispensary, Authentication Suite, System Errors, and UI Elements.
  • Dual Theme Mode: Native Dark and Light themes with animated View Transitions and frosted glassmorphism backdrops.
  • Bi-directional (LTR & RTL): Full Right-to-Left (RTL) language support with instantaneous toggle for international hospital deployments.
  • Dynamic 8-Color Accent Switcher: Emerald, Teal, Ocean Blue, Violet, Amber, Rose, Aqua Cyan, and Indigo with real-time CSS variable shade generation.
  • Lenis Smooth Scrolling: Silky-smooth desktop scrolling experience integrated at root.
  • Rich Interactive Visualizations: Live vital telemetry charts, patient admissions area graphs, ward occupancy donuts, and clinical performance radars powered by ApexCharts and Recharts.
  • Code-Splitting & Lazy Loading: Dynamic page-level routing with React Router v7, clean component isolation, and zero console errors or warnings.
  • Clean & Modular Codebase: Strict component isolation, reusable UI library, and zero arbitrary Tailwind bracket classes (-[...]).

5. Installation Guide

Follow these quick steps to get CarePulse up and running on your local machine.

System Prerequisites:

  • Node.js: v18.0.0 or higher (v20+ LTS recommended). Check with node -v.
  • Package Manager: npm (v9+), yarn, or pnpm. Check with npm -v.
  • Browser: Modern Chromium (Chrome, Edge, Brave), Firefox, or Safari with modern CSS support.

Step 1: Extract the Archive

Download the ZIP archive from ThemeForest and extract it to your preferred working directory.

Step 2: Open Terminal in Project Folder

Terminal 
cd carepulse

Step 3: Install Node Dependencies

Execute your preferred package manager to install all required libraries:

Terminal 
# Using npm (recommended)
npm install

# Or using yarn
yarn install

# Or using pnpm
pnpm install

Step 4: Launch the Development Server

Start the Vite development server with Hot Module Replacement (HMR):

Terminal 
npm run dev

Your terminal will display the local development URL, typically:
Server active: Open http://localhost:5173 in your web browser.

6. Deployment & Production Build

To compile and optimize CarePulse for a production environment:

Terminal 
npm run build

This command compiles all JSX, minifies stylesheets, tree-shakes unused dependencies, and generates an optimized production bundle inside the dist/ directory.

Preview the Production Build Locally

Terminal 
npm run preview

Deployment Targets:

  • Vercel: Import the repository and set the framework preset to Vite. The build command is npm run build and the output directory is dist. Ensure client-side routing redirect is configured in vercel.json.
  • Netlify: Connect your Git repository, set the build command to npm run build, and publish directory to dist. Ensure client-side routing redirect is configured (/* /index.html 200).
  • Apache / Nginx / Traditional Hosting: Upload all files inside dist/ directly to your web server root (public_html or /var/www/html). Ensure fallback routing to index.html is enabled for React Router.

7. Theme & Dark Mode Management

CarePulse features a comprehensive, state-of-the-art theme system managed via ThemeProvider in src/context/theme-context.jsx. It provides persistent theme state in localStorage and animated View Transitions API support with circular reveals.

How to Change the Default Theme Mode:

By default, CarePulse opens in dark mode (ideal for telemetry monitors and clinical command centers). If you prefer light mode by default, open src/context/theme-context.jsx and edit line 49:

src/context/theme-context.jsx 
// src/context/theme-context.jsx
// Change "dark" to "light" for clinical light mode default:
const [theme, setTheme] = useState("light");

Accessing Theme State via Hook:

You can read or toggle the theme anywhere in your application using the custom useTheme() hook:

8. Color Customization & Accent Switcher

CarePulse features a dynamic primary color system. When an accent color is selected in the Settings Drawer or programmatically, the application automatically computes CSS variables for --primary-color, --primary-rgb, and all 11 tint/shade stops (--primary-50 to --primary-950).

Changing the Default Primary Accent:

Open src/context/theme-context.jsx and modify the DEFAULT_PRIMARY constant (default is Clinical Emerald Green #22c55e):

src/context/theme-context.jsx 
// src/context/theme-context.jsx
// Change to any hex color of your clinical institution's brand:
const DEFAULT_PRIMARY = "#22c55e"; // Clinical Emerald default

9. Font Customization

CarePulse uses Google Web Fonts: Plus Jakarta Sans for prominent UI headings and IBM Plex Sans for clear, accessible medical telemetry values, charts, and table figures.

How Typography is Configured:

In src/index.css under the @theme definition:

src/index.css 
/* src/index.css */
@theme {
  --font-sans: "IBM Plex Sans", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
  --font-display: var(--font-sans);
  --font-body: var(--font-sans);
  --font-mono: var(--font-sans);
}

To Change the Font Family:

  1. Visit Google Fonts and select your preferred font (e.g. Inter, Outfit, Montserrat, Roboto).
  2. Copy the provided <link> or @import tag into index.html or src/index.css.
  3. Update --font-sans under @theme in src/index.css.

10. RTL (Right-to-Left) & Bi-directional Support

CarePulse provides full, out-of-the-box support for Right-to-Left (RTL) languages such as Arabic, Hebrew, Persian, and Urdu for international hospital deployments.

How Direction Works:

  • Managed via toggleDirection() in ThemeContext (src/context/theme-context.jsx).
  • Dynamically toggles the dir="rtl" or dir="ltr" attribute on the root <html> element.
  • Tailwind CSS v4 logical properties (e.g., ps-, pe-, ms-, me-, border-s, border-e, start-, end-) automatically flip all alignments, paddings, and margins seamlessly.
  • Telemetry curves and charts are wrapped with dir="ltr" to preserve exact Cartesian telemetry coordinates.

Set RTL as the Default Direction:

Open src/context/theme-context.jsx and update line 50:

src/context/theme-context.jsx 
// src/context/theme-context.jsx
// Change "ltr" to "rtl" for right-to-left default startup:
const [direction, setDirection] = useState("rtl");

Frequently Asked Questions (FAQ)

Answers to common developer and configuration questions:

How do I replace hospital branding with my own clinic name?

Open src/components/layout/Navbar.jsx and Sidebar.jsx to replace the title. Replace public/favicon.svg with your custom logo file.

Can I use this template with TypeScript?

Yes! TypeScript types are already declared in package.json (@types/react, @types/react-dom). You can rename files to .tsx as needed.

Why does CarePulse avoid arbitrary Tailwind bracket classes?

Strictly avoiding arbitrary bracket classes (-[...]) guarantees cleaner code, zero CSS bloat, and complete adherence to design tokens and hardware-accelerated styles.
